# 2026-10-28

## Session 1 — Correct checkout durability after Windows onboarding

**Goal:** Under [approved scope #12](https://github.com/Motor-Learning-Lab/HILD/issues/12), correct the specific Windows Claude Code skill-symlink failure observed in the [live onboarding pilot](https://github.com/opherdonchin/HILD-onboarding-ipad-2026-10/pull/2), without adding another adapter or changing host Git configuration automatically.

**Observed failure:** The installer successfully created `.claude/skills` on native Windows and passed its initial verification, but the target repository had `core.symlinks=false`. After the researcher squash-merged the installation PR and the agent checked out `main`, Git materialized the tracked link as an ordinary text file. Verification failed and skill discovery was impaired. The researcher authorized a local configuration and checkout repair; the host's [journal](https://github.com/opherdonchin/HILD-onboarding-ipad-2026-10/blob/main/HILD/journal/2026-10-28.md) records this.

**Changes in [PR #11](https://github.com/Motor-Learning-Lab/HILD/pull/11):**
- Added a read-only `core.symlinks` preflight for Claude installations. Explicit `false` fails everywhere; on native Windows the setting must be explicitly `true`. The user must separately authorize any local configuration change; the installer does not perform it.
- Made `--verify` report an unsafe setting even while the initially created symlink still exists.
- Added regression tests for refusal before preview/apply, failure after a formerly successful install, and a native Windows fresh clone with `core.symlinks=false` that materializes a plain file.
- Updated the [first-install guide](../../.agents/skills/hild-integrate/first-install.md) with the rationale, remedy and need for verification after checkout.

**Evidence:** Both the [Windows/Linux installation CI](https://github.com/Motor-Learning-Lab/HILD/actions/runs/40745941095) and [mechanical CI](https://github.com/Motor-Learning-Lab/HILD/actions/runs/40745941093) passed at [`37d094e`](https://github.com/Motor-Learning-Lab/HILD/commit/37d094efa0c1fe0c40c5fba565ec0e0abd1daa60). Automated tests do not demonstrate live agent adoption behavior.
